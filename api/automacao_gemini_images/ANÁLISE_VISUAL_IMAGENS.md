## 🎯 Padrões Consolidados

### **LOFI - Elementos Obrigatórios**
```
✅ Pessoa com pele escura/afro
✅ Fones de ouvido SEMPRE presentes (pretos, premium-looking)
✅ Olhos FECHADOS (postura meditativa)
✅ Expressão serena e contemplativa
✅ Roupas escuras (turtleneck, sweater, camiseta básica)
✅ Fundo neutro (cinza, preto, verde-escuro)
✅ Iluminação direcional/lateral com halos
✅ Partículas de luz flutuantes
✅ Bokeh cinematográfico suave
✅ Qualidade 8K, fotografia editorial
```

### **SOUL WORSHIP - Elementos Obrigatórios**
```
✅ Pessoa com pele escura (confiante, empoderada)
✅ Fones modernos (podem ser ouro/dourados)
✅ Olhos fechados OU com foco contemplativo
✅ Postura ereta e confiante
✅ Roupas com padrão ou cores definidas
✅ Fundo colorido (azul, ouro, tons quentes)
✅ Iluminação dramática e cênica
✅ Mão frequentemente tocando o fone
✅ Elementos de interação/movimento sugerido
✅ Atmosfera espiritual/empoderada
```

### **JAZZ - Inferência (Baseado em Padrões)**
```
✅ Estilo vintage/retro com tons quentes
✅ Sofisticação e artístico
✅ Ouro, âmbar, cores vibrantes
✅ Postura pensativa mas engajada
✅ Fones vintage ou modernos estilizados
✅ Atmosfera de jazz club ou estúdio
```

## 💡 Insights Técnicos

### Diversidade
- Todas as imagens são de pessoas com pele escura (intencional e inclusivo)
- Representação forte de mulheres
- Diversidade de texturas de cabelo

### Fones de Ouvido
- **100% de presença** em todas as imagens
- Elemento identificador chave do gênero
- Sempre prominent e visível

### Iluminação
- **Chave para diferenciação**:
  - Lofi: Direcional, suave, halos
  - Soul: Dramática, cênica, colorida
- Nenhuma iluminação "neutra" ou plana

### Backgrounds
- Nunca fotografias de ambientes reais
- Sempre fundos pintados/degradês
- Cores ajudam a identificar gênero

### Pós-Processamento
- High-end color grading
- Bokeh cinematográfico
- Partículas de luz sutis
- Contraste controlado
